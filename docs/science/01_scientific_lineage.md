# 科学的背景と先行研究の読み方

魚に取り付けたタグの水温・深度記録は、その魚が経験した環境の時系列です。位置推定では、この記録を海洋モデルや海底地形などの空間情報と比べ、記録と整合する候補位置を探します。さらに、時間的に離れた観測を移動モデルで結び付け、位置と経路の不確実性を求めます。pangeo-fish は、バイオロギングデータと地球科学データを使って魚の移動を調べる Python パッケージとして、JOSS の論文で公表されています。{cite:p}`Magin2026`

この章では、pangeo-fish がどのような先行研究の流れの上にあるかを紹介します。論文の考え方と、ソフトウェアの実際の計算式や既定値は同じとは限りません。細かい設定は、各章とパラメータの章で説明します。

## 先に押さえる三つの層

| 層 | 問い | この資料で扱うもの |
|---|---|---|
| 観測モデル | その場所に魚がいたとすると、観測はどの程度もっともらしいか | 水温、音響検出、海底地形、潮汐から作る尤度（likelihood）（各場所が記録とどれだけ合うかの点数） |
| 移動・推論モデル | 前後の時刻の候補位置はどのようにつながるか | HMM、移動カーネル、フィルタ、平滑化、経路の要約 |
| 空間表現・計算 | 候補位置をどう表し、大量の環境データをどう処理するか | HEALPix、WGS84 楕円体、Xarray、Dask、Zarr |

したがって、「HMM と水温のどちらを使うか」という比較は適切ではありません。実際には、HMM の中で、水温から作った尤度（likelihood）を使う、という組み合わせになります。HEALPix は位置の表現を定める格子であり、タグ観測から新しい情報を生み出す観測モデルではありません。

## pangeo-fish に近い研究一覧

Gonse らの研究は、pollack の音響テレメトリーとアーカイバルタグを組み合わせて位置を推定した実例です。2022年からイギリス海峡に設置された音響受信機網を使い、83尾に音響発信機を付け、うち48尾にはデータ記録型タグも付けました。回収された10尾について、音響検出と水温・深度の時系列を位置推定モデルで統合して経路を再構成しています。{cite:p}`Gonse2025` 受信機網の外側でも、環境の記録から位置を推定し、検出の情報を加える、という研究です。

音響検出の尤度（likelihood）を既存の位置推定モデルに加える方法は、Goossens らが報告しています。{cite:p}`Goossens2023`

ワークショップのデモは、この Gonse らの論文のタグ A19124 を使い、IBI 再解析の日平均と HEALPix level 10 で計算します（{doc}`../pangeo-fish`）。論文自体の時間刻み、格子、海洋モデル、音響の扱いは、論文の本文を見てください。このデモは論文の再現実験ではなく、ソフトウェアの使い方の例です。

音響情報を入れた経路と入れない経路の距離は、情報を追加したときに結果がどれだけ変わるかを示すものです。位置の誤差そのものではありません。位置の誤差を知るには、推定に使っていない、独立した既知の位置と比べる必要があります。独立した位置情報の集め方や検証方法の選び方は、Gatti らが整理しています。{cite:p}`Gatti2021`
