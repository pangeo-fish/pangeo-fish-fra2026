# 日本語の科学・技術解説を読むために

この資料は、FRA 横浜ワークショップ（2026年11月25日 10:00〜12:00）の実習と、その後の個別のタグデータの相談で使う、pangeo-fish の科学・技術リファレンスです。魚の位置が直接観測されない時間帯に、タグの記録、海洋モデル、受信記録、移動の仮定から、どの位置や経路が整合的かを考えます。理論を読む順番と、ノートブックを実行する順番は同じでなくてかまいません。

実習ではまず Base ノートブック（水温と音響テレメトリー）で全体の流れをつかみます。その続編の Complete ノートブックでは、海底地形と潮汐を加えます（ノートブックの題名に「仮」とあるとおり、準備中の部分があります）。個別のタグデータの相談では、使いたい観測の章から入り、必要に応じて HMM、楕円体 HEALPix、パラメータ表へ戻ってください。個別相談の日程は{doc}`../agenda`に掲載しています。

## 全体像

**全体の読み方。** 水温・音響・海底地形・潮汐は、各時刻の候補位置に重みを与えます。HMM はその重みを移動モデルで時間方向につなぎます。HEALPix は位置を表す離散格子です。HMM、観測情報、格子は、それぞれ異なる役割を担っています。

## 説明で使う言葉

| 用語 | この資料での意味 |
|---|---|
| 観測確率（emission probability）・尤度・観測重み | ある位置を仮定したとき、観測との整合性を表す量。実装が経験的なスコアの場合は、そのことを明記します |
| 位置推定 | 直接観測されない魚の位置や経路を、タグの記録などから推定すること（geolocation） |
| 確率質量 | 離散セルに割り当てられた確率。全候補セルの和が1になります |
| フィルタ分布 | その時刻までの観測を使う位置分布 |
| 平滑化分布 | 解析期間全体の観測を使う各時刻の位置分布 |
| 平均・最頻・Viterbi | 異なる要約。一本の線にまとめるとき、何を選んだかを明示します |
| 空間解像度 | 計算・データの空間的な細かさ。位置推定の精度とは別に評価します |
| 精度の検証 | 推定に使っていない位置情報などに照らして確かめること |
