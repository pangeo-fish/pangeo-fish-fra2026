# 海底地形による制約：潜れた深さとセル内の地形

海底地形から得られる基本的な条件は、魚が記録した水深まで潜れる水柱が、その場所に存在することです。これは、魚が常に海底にいるという仮定より弱い条件です。浮魚性の魚にも、観測した潜水深度より浅い海域を候補から減らすという使い方ができます。

**実装の基準**：以下の関数、数値、挙動は、pangeo-fish `main` の `e2877f2` のソース（`pangeo_fish/bathy.py` と `notebooks/pangeo-fish-complete-demo.ipynb`）を読んで確認したものです。コードの記述は読解にもとづくもので、ノートブックを実行して確かめたものではありません。説明用の理想式と実際の実装は分けて示します。

## 1. 水深の符号と基準面

海底水深 $H(x)>0$ を平均海面から下向き、海面高度 $\eta(x,t)$ を上向き、タグ水深 $d(t)>0$ をその時点の海面から下向きに定義すると、物理的な条件は

$$
d(t)\leq H(x)+\eta(x,t)
$$

です。海底が動かない近似の下で、海底地形と比較する深さを

$$
z_t^*(x)=\max_{i\in\text{time bin }t}\{d_i-\eta(x,t_i)\}
$$

と書けます。この式は座標の定義から導いた本教材の説明です。実際の処理（`bathy.py` の `compute_pdf_bathy_numba_like_numpy`）では、時間ビンごとにタグの `pressure` の最大値（dbar を m とみなした値）から `XE`（参照モデルの海面高度）を引いた値が、海底地形と比べる深さになります。圧力の単位変換のコードはなく、元データが dbar 以外なら事前の変換が必要です。ただし最大の圧力が12,000を超えると、dbar としては深すぎる（Pa の可能性がある）として `ValueError` になります。`XE` に潮汐や基準面差のどこまでが含まれるかは、選んだ参照モデルごとに確認します。

GEBCO2024 は、標高を m で持つ15秒角格子で、海底は負の値になります。公式資料は平均海面基準を仮定しつつ、浅海の一部には異なる基準面の資料が含まれることを明記しています。また、格子間隔と元の測深データの実効的な解像度は等しくありません。{cite:p}`GEBCO2024`

## 2. なぜセル中心の水深だけでは足りないか

一つの HEALPix セルに大陸棚斜面が入れば、浅い部分と深い部分が共存します。セル中心の水深だけを使うと、同じセル内に実際には潜れる場所があるのに候補から除く場合があります。逆に最大水深だけを使えば、深い小部分だけがあるセルに強い重みを与える場合があります。

この違いを説明する理想化として、セル $c$ の中の水深を $H$、その分布を $p_c(H)$ とすると、深さ $z$ が可能な割合は

$$
S_c(z)=\Pr(H\ge z\mid c)=\int_z^\infty p_c(H)\,dH
$$

になります。$S_c$ は水深の生存関数です。名称に「生存」とあっても、ここでは魚の生存確率を意味しません。

例えば、同じセル内に等しい重みの8地点があり、その水深が25、35、…、95 mなら、60 mより深い4地点の割合は $1/2$ です。この値は合成した説明例であり、実際の魚がその4地点に等確率で存在するという観測結果ではありません。セル内の利用可能面積、元ラスタのサンプリング重み、魚の生息場所選択が違えば、適切な重み付けも変わります。

### 海底地形の不均質性を調べる先行研究

Nielsenらは、北太平洋の平坦・斜面・不均質な海底で模擬移動を作り、深度を用いたHMMの格子幅とセル内深度分散の指定を比較しました。出版社に掲載された要旨では、セル内の深度分布が正規分布から外れると性能が低下し、格子を粗くする影響や推定される拡散の値も地形・分散の指定に依存したと報告します。新しい海域で感度分析が必要という論点に直結します。{cite:p}`Nielsen2019`

この研究が現在のヒストグラム由来の深度適合度を検証したわけではありません。本章への応用は、**水平セルの大きさと鉛直の深度ビン幅を別々に変え、観測重みと推定移動幅の変化を確認する**という検証方針です。これは論文の結果から導く提案であり、特定の格子・ビン幅が最適だという主張ではありません。

## 3. Pangeo-Fish の実装との対応

`compute_healpix_histogram_region_bin_size` は、各セルについて、そのセルに入る GEBCO の水の点（標高が負の点で、陸の点は除く）の水深を、標準偏差 `stdev`（m）の正規分布として広げ、水深ビンに配分します。そして「海底が深さ `d` m 以上である確率」を、ビンの境界の深さ `d` ごとに保存します（変数名 `bathy_pixel_hist`、水深軸 `depth_bins`）。この確率は1から深さとともに減ります。これが前節の $S_c(z)$ に対応します。`batch_compute_pdf_bathy` は、時間ステップごとに、魚が届いた最大の深さ（`max(pressure) - XE`）でこの確率を読みます。境界の間は線形補間し、最初の境界より浅ければ最初の値、最後の境界より深ければ最後の値を使います。

| 項目 | 関数の既定値 | Complete デモで与えた値 | 備考 |
|---|---|---|---|
| `depth_bin_size` | 1（m） | 2 m | 深度ビンの幅（m）。尤度はビン内で線形補間される |
| `max_depth_m` | `None` | 1000 m | `nb_depth_bins` と `max_depth_m` のどちらかが必須で、どちらもなければ `ValueError`。`nb_depth_bins = ceil(max_depth_m / depth_bin_size)` なので、デモでは500区間。最後の境界はちょうど `max_depth_m` で、最後の区間は短くなりうる |
| `depth_offset` | 0 | 指定なし | 魚と海底の間の余裕（m）。水深を `-elevation - depth_offset` として求める。負の値なら、その分だけ海底より下を許す |
| `default_stdev_m` | 1（m） | 指定なし | `stdev` がない、または有限でない点の水深の不確かさ（m） |
| `chunk_size` | 500 | 指定なし | 一度に読む緯度の行数（ヒストグラムの集計を行う単位） |
| `ellipsoid` | `"WGS84"` | 研究設定の `ellipsoid`（配布デモの値は `"WGS84"`） | セルIDとセル中心の計算に使われる（下記） |
| 入力の海底地形 | 関数に渡すデータセット（`elevation`（m、海底は負）が必須、`stdev`（m）は任意） | `gebco_2024_new.zarr`。領域（`bbox`）の外側に0.1度の余白を付けて切り出す | |
| `batch_compute_pdf_bathy` の `batch_size` | 50,000（セル） | 10,000 | 一度に水深尤度を計算するセル数 |

`ellipsoid` は、地理座標からセルIDを求める段階（`lonlat_to_healpix`）と、出力のセル中心の `latitude`／`longitude` を求める段階（`healpix_to_lonlat`）の両方に渡されます。出力の `cell_ids` には、属性として `grid_name`、`level`、`indexing_scheme`、`ellipsoid` が付きます。`batch_compute_pdf_bathy` は、ヒストグラムと `diff-regridded.zarr` で level・番号付け・楕円体が違うと `ValueError` にします。

実装出典：[bathy.py のヒストグラム](https://github.com/pangeo-fish/pangeo-fish/blob/e2877f2/pangeo_fish/bathy.py#L50-L214)、[Complete デモの設定](https://github.com/pangeo-fish/pangeo-fish/blob/e2877f2/notebooks/pangeo-fish-complete-demo.ipynb)（Section 6）。

### 水深ビンと `stdev` の単位

ヒストグラムの水深軸 `depth_bins` は m の境界値で、海面より上の10ビンぶん（`-10 × depth_bin_size`）から、最後の境界（`max_depth_m`、または `nb_depth_bins × depth_bin_size`）まで続きます。この「10」は、海面より上に残すビン数を表す実装上の定数（`_ABOVE_BINS`）です。水深を引く側も、同じ m の `depth_bins` を使って位置を探すので、ビン幅を変えても二つの側は同じ軸の上で一致します。出力の `bathy_pixel_hist` は、先頭の境界で1になるように規格化されます。

**この `10` に対して、測深誤差補正、海図基準面補正、一定の安全余裕といった意味を根拠なく付けません。** ソースでは、海面より上に残すビン数を表す定数です。

各 GEBCO 点は、平均が水深（`depth_offset` を引いた値）、標準偏差が `stdev` の正規分布として、ビンの境界の間に配分されます。`stdev` は**m**の単位で使われ、`depth_bin_size` とは独立です。入力に `stdev` がなければ全点に `default_stdev_m`（既定1 m）が使われ、`stdev` が有限でない点にも `default_stdev_m` が使われます。いずれの場合も最小値は0.001 mに切り上げられます。これらを一般に推奨される測深誤差として説明しません。なお、デモで使うラスタに `stdev` が含まれるかどうかは、ソースからは確認できていません。

現段階では、この項を「水深との適合度」または「セル内の水深分布に基づく位置重み」と説明するのが明確です。特定海域の測深誤差を校正し、魚のセル内分布を含めて妥当性を確かめる前に、校正済みの確率と呼びません。

実装出典：[水深値の索引、床値、欠測処理](https://github.com/pangeo-fish/pangeo-fish/blob/e2877f2/pangeo_fish/bathy.py#L216-L257)、[セルへの割当てと出力](https://github.com/pangeo-fish/pangeo-fish/blob/e2877f2/pangeo_fish/bathy.py#L382-L499)。

## 4. 欠測、床値、正規化

陸の GEBCO 点（標高が0以上）と欠測の点は、ヒストグラムの集計から除かれます（`bathy.py` 132、149行）。全点が陸のセルにはヒストグラムができません。

水深尤度の側では、`XE` が欠測のセル（陸）と、ヒストグラムの先頭の値が欠測のセルには `NaN` が返ります（232行）。海のセルで、ヒストグラムに対応するセルがない場合は、最も近いヒストグラムのセルの値が使われ、その数と最大距離が `UserWarning` で知らされます（340–379、457–468行）。時間ステップにタグの水深記録が全くない場合は、情報なしとして1が返ります（241–243行）。海のセルの値は、床値 `1e-14` 以上に切り上げられるので、常に完全な0の排除にはなりません（256行）。床値と欠測と1は別の意味を持ちます。

読み出す深さが最初の境界以下なら最初の値、最後の境界以上なら最後の値になります（246–250行）。すなわち、設定した最大水深（デモでは1000 m）より深い観測は、「その最大水深より深い海底の割合」で扱われます。

空間的な正規化は、ある時刻のセル間比較をしやすくします。デモでは、`batch_compute_pdf_bathy` の出力を、全セルの和（`NaN` を除く）で割って正規化しています。ただし、総和を1にしたというだけで海底地形の不確実性や生息場選択をすべて含む事後確率になるわけではありません。最終的な位置分布は、ほかの観測と HMM の移動・端点条件を加えて決まります。

`NaN` を含む観測項が積に入ると、そのセルを失う場合があります。各時刻で有効セル数と正の重みの総量を確認し、海底地形を追加した直後に候補が消えていないかを見ます。これは推定結果の善し悪しを判断する前の、入力の整合性の確認です。

## 5. 潮汐項との組み合わせ

水深の最大値から海底地形項を作り、同じ時系列の周期変動から潮汐項を作ります。情報の特徴は異なるが、元の観測は共有されています。legacy 潮汐のように、モデルの水柱厚 `WCT` を使って絶対水深を既に比較に含める場合は、海底地形の条件が重複する可能性を特に説明します。

HEALPix 方式の潮汐（`water_column=None`）は、セルごと・日ごとに平均水深を推定して取り除くため、絶対水深と波形の役割を分けやすいです。Complete デモは、絶対水深の情報を別の海底地形項に任せています。ただし、そのことだけで両項の条件付き独立性が証明されたわけではありません。比較実験では、海底地形の追加で分布が狭くなるだけでなく、独立の既知位置をどれだけ含むかを調べます。

## 6. 面談で使う確認表

| 相談事項 | 見たい図・資料 | 判断へのつながり |
|---|---|---|
| 対象海域の海底地形は十分か | GEBCO の TID と、利用可能なら局所測深との比較 | 直接測深・補間などのデータ来歴を把握する |
| タグは何を記録したか | pressure/depth の単位、校正資料、変換式 | m と dbar の混同を避ける |
| 深度の基準面は揃っているか | 海面高度、平均海面、海図基準面の関係図 | 系統的な水深差を見分ける |
| 格子とビン幅の影響は何か | level・水深ビン幅を変えた適合度地図 | 空間離散化と鉛直離散化の影響を分ける |
| 小さな深場が支配していないか | セル内ヒストグラムと生存関数 | 単一の代表水深では見えない構造を確認する |

GEBCO の TID は元データの種類を示す資料であり、各セルの数値的な標準偏差をそのまま提供する変数と同一視しません。デモで使うラスタに `stdev` がある場合は、誰がどの計算で作った変数かまで記録します。{cite:p}`GEBCO2024`
