# 個別相談：自分の魚・タグ・海域へ適用する

個別のタグデータの相談の日程は、{doc}`../agenda` に掲載しています。このページは、相談のときや、自分で始めるときに、使えるデータから研究上の問いへ戻り、どの情報が位置の手がかりになるかを考えるための手引きです。すべての観測（水温、音響、海底地形、潮汐など）を最初から使うことを目標にせず、その事例に合うモデルを組みます。

## 1. 最初に決める研究上の問い

| 問い | 必要になる検討 |
|---|---|
| 季節ごとの滞在海域を知りたい | 長期欠測、滞在分布、環境場の季節変化 |
| 沿岸と沖合の往復を知りたい | 海岸のマスク、沿岸モデル誤差、独立な受信情報 |
| 日ごとの移動経路を知りたい | 時間刻み、移動σ、位置の手がかりが十分にあるか |
| 行動ごとの移動特性を知りたい | 行動の定義、観測から付けた行動のフラグと本当の行動の区別、各行動の移動の例が十分にあるか |
| 海洋環境との関係を議論したい | 推定に使った環境と、説明変数として再利用する環境の依存 |

最後の点は研究設計上、重要です。温度を使って位置を推定し、得られた位置の温度から温度選好を論じると、推定の過程と結論が結び付いてしまいます。どの情報で位置を決め、どの情報で生態の仮説を評価するのかを、あらかじめ整理してください。

## 2. 相談で確認するデータ

| 分類 | 持ち寄る内容 | 決めること |
|---|---|---|
| 対象 | 種、個体数、期間、海域、生活史 | どの移動尺度を表すか |
| タグ | 型式、温度・圧力・深度・光、記録間隔 | 単位変換、時間ビン、誤差の仮定 |
| イベント | 放流、回収、再捕、死亡、浮上 | 位置・時刻の誤差と、どのイベントを使うか |
| 音響 | 検出、設置期間、停止、受信範囲試験 | 未検出をどこまで制約に使うか |
| 環境モデル（参照モデル） | 製品名、領域、期間、変数、鉛直座標 | 入力の対応、モデル誤差の推定方法 |
| 地形・潮汐 | データ版、基準面、調和定数、潮汐の大きさ | 使う観測と前処理 |
| 検証 | 推定に使わず保留できる位置情報 | 精度と不確実性の評価方法 |

この表は聞き取りのための書式です。埋まっていない項目を、黙ってデモの値で補うためのものではありません。足りない項目は、その欠如が影響する仮定とともに記録してください。

## 3. データ条件ごとの入口

**温度・深度だけがある場合。** まず、モデルの被覆と鉛直方向の対応、温度の違いで位置を絞れるかを確認します。既知の放流・終点は役に立ちますが、狭い初期分布だけで途中の経路の精度が保証されるわけではありません。必要なら深度の制約を追加し、独立した検証の計画を立てます。

**音響テレメトリーとアーカイバルタグが同じ個体にある場合。** タグ ID と時刻を対応させ、受信範囲の情報を入力します。未検出を利用するには、受信機が設置されていたという情報に加え、実際の稼働状況と検出の性質を議論する必要があります。検出の一部を保留して、追加した環境情報の予測性能を評価することもできます。

**底生・着底に近い深度パターンがある場合。** 深度に潮位の変動が見える可能性を検討します。ただし、魚の鉛直移動、斜面上の移動、圧力のオフセット、うねり、非潮汐の海面変動も検討してください。自動検出したフラグだけで着底を断定してはいけません。

**外洋・浮遊性の種の場合。** 深度と潮汐からの位置の制約が、同じように働くとは限りません。光、浮上位置などを含む別の方法との比較が必要になることがあります。光を使う方法は、今回のノートブックでは扱いません。

## 4. 日本周辺のモデルを持ち込む場合

FRA-ROMS などを使う場合は、次の順で適合性を確認します。

1. 格子・座標系、時間、深度、温度、海面高度、海底深度の定義を読みます。
2. タグの期間と海域を含む小さな部分を取り出し、時系列と鉛直プロファイルを描きます。
3. モデルのネイティブ格子で物理量の比較を検証してから、HEALPix への変換を調べます。
4. 海陸マスク、陸や欠測をまたぐ補間、格子の楕円体と ID を検証します。
5. 既知の位置または合成データで整合性を確かめ、実際の個体に進みます。

海洋モデルの解像度、沿岸域の誤差、観測の密度が、細かい格子の設定以上に重要になる場合があります。

## 5. 相談のはじめに聞くこと：魚とタグについて

魚の動き方とタグの種類で、使える手がかりと、推定の進め方が変わります。次のことを、分かる範囲で教えてください。分からないことは「分からない」で構いません。

**魚の動き方**

- **どんな動きをする魚ですか。** 海底の近くにいることが多いですか。中層や表層ですか。岸の近くと沖を行き来しますか。
- **1 日に、どのくらいの距離を泳ぎますか。** おおよそで構いません。この距離の見積もりは、位置を絞り込むときに効きます。
- **じっと動かない時間はありますか。** 海底でじっとしている時間があれば、圧力の変化から潮の満ち引きが読み取れるかもしれません（{doc}`07_tides`）。
- **季節によって、いる場所は変わりますか。** 産卵や回遊の時期があれば教えてください。

**タグ**

- **どんなタグですか。** 体の外側に取り付けるタイプですか。体の中に入れるタイプですか。
- **何を、どのくらいの間隔で記録していますか。** 水温、深度（圧力）、光、加速度などです。
- **記録はどのように終わりますか。** 魚から外れて浮くか、魚と一緒に回収されるか、などです。放流から回収までの間に、船の上や陸の上の記録が混ざっていないかも確かめます。
- **体温が水温と違う魚ですか。** たとえばマグロの仲間では、タグの温度を、そのまま水温として使えない場合があります。

**そのほかの手がかり**

- **放流した場所と回収した場所は分かりますか。** 位置と時刻の誤差も分かる範囲で教えてください。
- **音響の受信機の近くを通りましたか。**

## 6. 相談の最後に残すメモ

相談の最後に、次の 7 項目を 1 枚にまとめて残します。相談の担当者と一緒に、短く書いてください。

- **知りたいこと：** 何を調べたいか。
- **使うデータ：** 個体、期間、海域、タグ、そのデータを使ってよいか。
- **使う手がかり：** 水温、音響、海底地形、潮汐のうち何を使うか、その理由。
- **仮定したこと：** 誤差、泳ぐ距離、時刻のずれ、記録の欠け。
- **最初に試すこと：** 小さい範囲で、何を固定し、何を変えるか。
- **結果の確かめ方：** 推定に使わない位置の情報（回収位置など）と、何を見て評価するか。
- **あとで同じ結果を出すための記録：** pangeo-fish のコミット、環境、データの版、設定の保存場所。

具体的なパラメータは[対応表](11_parameters_versions.md)、比較実験の設計は[比較と検証](08_comparison_validation.md)を参照してください。
