# 個別相談：自分の魚・タグ・海域へ適用する

個別のタグデータの相談の日程は、{doc}`../agenda` に掲載しています。このページは、相談のときや、自分で始めるときに、使えるデータから研究上の問いへ戻り、どの情報が位置を識別できるかを考えるための手引きです。すべての観測項を最初から有効にすることを目標にせず、その事例に合うモデルを組みます。

## 1. 最初に決める研究上の問い

| 問い | 必要になる検討 |
|---|---|
| 季節ごとの滞在海域を知りたい | 長期欠測、滞在分布、環境場の季節変化 |
| 沿岸と沖合の往復を知りたい | 海岸のマスク、沿岸モデル誤差、独立な受信情報 |
| 日ごとの移動経路を知りたい | 時間刻み、移動σ、観測の識別力 |
| 行動ごとの移動特性を知りたい | 行動の定義、観測フラグと潜在状態の区別、十分な遷移数 |
| 海洋環境との関係を議論したい | 推定に使った環境と、説明変数として再利用する環境の依存 |

最後の点は研究設計上、重要です。温度を使って位置を推定し、得られた位置の温度から温度選好を論じると、推定の過程と結論が結び付いてしまいます。どの情報で位置を決め、どの情報で生態の仮説を評価するのかを、あらかじめ整理してください。

## 2. 相談で確認するデータ

| 分類 | 持ち寄る内容 | 決めること |
|---|---|---|
| 対象 | 種、個体数、期間、海域、生活史 | どの移動尺度を表すか |
| タグ | 型式、温度・圧力・深度・光、記録間隔 | 単位変換、時間ビン、誤差の仮定 |
| イベント | 放流、回収、再捕、死亡、浮上 | 位置・時刻の誤差と、どのイベントを使うか |
| 音響 | 検出、設置期間、停止、受信範囲試験 | 未検出をどこまで制約に使うか |
| 環境モデル（参照モデル） | 製品名、領域、期間、変数、鉛直座標 | 入力の対応、モデル誤差の推定方法 |
| 地形・潮汐 | データ版、基準面、調和定数、潮汐の大きさ | 適用する観測項と前処理 |
| 検証 | 推定に使わず保留できる位置情報 | 精度と不確実性の評価方法 |

この表は聞き取りのための書式です。埋まっていない項目を、黙ってデモの値で補うためのものではありません。足りない項目は、その欠如が影響する仮定とともに記録してください。

## 3. データ条件ごとの入口

**温度・深度だけがある場合。** まず、モデルの被覆と鉛直方向の対応、温度構造の識別力を確認します。既知の放流・終点は役に立ちますが、狭い初期分布だけで途中の経路の精度が保証されるわけではありません。必要なら深度の制約を追加し、独立した検証の計画を立てます。

**音響テレメトリーとアーカイバルタグが同じ個体にある場合。** タグ ID と時刻を対応させ、受信範囲の情報を入力します。未検出を利用するには、受信機が設置されていたという情報に加え、実際の稼働状況と検出の性質を議論する必要があります。検出の一部を保留して、追加した環境情報の予測性能を評価することもできます。

**底生・着底に近い深度パターンがある場合。** 深度に潮位の変動が見える可能性を検討します。ただし、魚の鉛直移動、斜面上の移動、圧力のオフセット、うねり、非潮汐の海面変動も検討してください。自動検出したフラグだけで着底を断定してはいけません。

**外洋・浮遊性の種の場合。** 深度と潮汐からの位置の制約が、同じように働くとは限りません。光、浮上位置などを含む別の方法との比較が必要になることがあります。ワークショップの Base／Complete ノートブックには光を使う経路は含まれていません。開発ブランチの例と、実行できる教材は区別してください。

## 4. 日本周辺のモデルを持ち込む場合

FRA-ROMS などを使う場合は、次の順で適合性を確認します。

1. 格子・座標系、時間、深度、温度、海面高度、海底深度の定義を読む。
2. タグの期間と海域を含む小さな部分を取り出し、時系列と鉛直プロファイルを描く。
3. モデルのネイティブ格子で物理量の比較を検証してから、HEALPix への変換を調べる。
4. 海陸マスク、陸や欠測をまたぐ補間、格子の楕円体と ID を検証する。
5. 既知の位置または合成データで整合性を確かめ、実際の個体に進む。

この手順は接続のための提案であり、FRA-ROMS で既に実行・検証済みという意味ではありません。海洋モデルの解像度、沿岸域の誤差、観測の密度が、細かい格子の設定以上に重要になる場合があります。

## 5. 相談の最後に残す一枚

相談ごとに、次の七項目を短くまとめてください。

- **研究の問い：** 何を比較・推定したいか。
- **対象データ：** 個体、期間、海域、タグ、利用権限。
- **使う観測項：** 水温、音響、海底地形、潮汐とその根拠。
- **仮定：** 誤差、移動、時刻、深度、未検出、欠測。
- **最初の実験：** 小さい範囲で何を固定し、何を変えるか。
- **検証：** 入力に使わない情報と評価量。
- **再現条件：** コミット、環境、データ版、格子、設定の記録先。

具体的なパラメータは[対応表](11_parameters_versions.md)、比較実験の設計は[比較と検証](08_comparison_validation.md)を参照してください。
