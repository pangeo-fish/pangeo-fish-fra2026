# 時間割

2026年11月25日（水）10:00〜12:00、水産研究・教育機構（FRA）横浜庁舎（対面）。

実習の時間をしっかり取れるよう、2 つのノートブックを一緒に動かしながら、その場で何が起きているかを説明します。時間内に終わらなかった部分や、省略したセクションは、終了後に自分のペースで進められます（この Book はオンラインに残ります）。

| 時刻  | 内容 |
| ----- | ---- |
| 10:00 | 導入：pangeo-fish と FRA 連携で何ができるか |
| 10:10 | 環境起動（ブラウザでログインするだけ）。待ち時間に Pangeo と HEALPix の話 |
| 10:20 | 実習1：GLORYS を Xarray で開き、日本周辺を切り出して HEALPix に載せる |
| 10:50 | 休憩 |
| 11:00 | 実習2：タグデータから軌跡推定まで。移動パラメータを一つ変えて再実行し、結果を比べる |
| 11:40 | その先へ：自分のタグで試すときの入力形式、FRA-ROMS、GFTS。質疑と[アンケート](feedback) |
| 12:00 | 終了 |

ワークショップの前に済ませておくこと（詳しくは [事前登録](users-getting-started)、できれば 11 月 22 日まで）：

- EGI Check-in に登録し、`vo.pangeo.eu` Virtual Organisation への参加を申請する（承認は手作業なので、早めに）。
- [Copernicus Marine](https://data.marine.copernicus.eu/register) の無料アカウントを作る。
- できれば、10:00 より前に Pangeo@EOSC にログインし、ワンクリック起動リンクで環境を一度起動しておく。当日の待ち時間を減らせます。
