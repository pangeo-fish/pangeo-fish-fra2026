# Project Pythia

:::{tip}
Project Pythia（https://projectpythia.org/）は Pangeo の教育ワーキンググループで、地球科学コミュニティ全体のための教育リソースです。
以下では、この取り組みの考え方を紹介します。Clyne らによる最近の発表資料（2022）も掲載しています。

詳しくは、Pythia の [About のページ](https://projectpythia.org/about.html#presentations-about-project-pythia)（英語）をご覧ください。
:::
    
## 概要
Project Pythia は、Python を軸にした学習資料の拠点です。資料はオープンソースで、コミュニティが所有し、地球科学に焦点を当て、質の高いものを目指しています。

## Project Pythia のメンバー
現在の Pythia のコアチームは[こちら](https://projectpythia.org/index.html#the-project-pythia-team)で見られます。Pythia はオープンで包括的なコミュニティです。参加の方法は[こちら](https://projectpythia.org/index.html#join-us)をご覧ください。

## Project Pythia の目標
1. _Pythia ポータル：_ 検索できるオンラインポータルです。キャリアのどの段階にある科学者にも、地球科学のための Python エコシステムにある数多くのパッケージを使いこなし、組み合わせて使えるようになるために必要な、教育コンテンツと実際の事例を提供します。

2. _クラウドに展開できる Pythia プラットフォーム：_ 軽量な Binder ベースのプラットフォームです。ポータルのコンテンツを、カスタマイズできる実行環境でクラウド上に「ワンクリック」で起動できるようにします。
