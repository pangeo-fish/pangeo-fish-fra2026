# Environmental Data Science Book 

## 概要
Environmental Data Science Book（略して EDS book、https://edsbook.org）は、環境科学で共同作業ができ、再現可能で、透明性のある研究を進めるために、データ・研究・オープンソースのツールの公開を紹介し、支援する、オープンでコミュニティ主導の「生きた」オンライン資料です。

## 誰のための本か
科学コミュニティは幅広いですが、EDS book が主な対象とする読者は次のとおりです。
* 環境科学の素養があり、AI やデータサイエンスの手法に関心がある研究者。
* 計算機科学の素養があり、環境データサイエンスに関心がある研究者。
* 環境分野の応用に向けた、再現可能で、誰もが参加でき、共有・共同作業しやすい AI とデータサイエンスに関心のあるすべての方。

# 貢献するには
EDS book は、上記の対象読者に限らず、誰からの貢献も歓迎しています。
中心となる GitHub の repository は公開されており、オープンソースのライセンスが付いています（[こちら](https://github.com/alan-turing-institute/environmental-ds-book)）。
実行可能なノートブックは、[EDS book Gallery の organization](https://github.com/eds-book-gallery) でホストされています。
参加の方法は、EDS の[貢献者ガイド](https://github.com/alan-turing-institute/environmental-ds-book/blob/master/CONTRIBUTING.md)（英語）をご覧ください。
